# 2026-11-19 리팩터링 기록

## 실제 변경
기존 단일 HTML의 CSS, 지도, 충돌/길찾기, 캐릭터 렌더링, 액션 이펙트, 폭주 대사, 관리 판정, 종족 대사, 오디오, 키보드/터치 입력, 상태 패널을 독립 ES 모듈로 분리.
원본 고화질 아라크네 WebP 4단계와 시작 화면 WebP도 GitHub 저장소에 포함.
상대경로 사용으로 GitHub Pages `/monstergirl/` 하위에서 작동하도록 구성.

## 주의
일반 웹페이지 파일 직접 열기(file://)에서는 JavaScript 모듈 보안 때문에 실행되지 않을 수 있습니다. 로컬 서버 또는 GitHub Pages를 사용하세요.
현재 `src/core/main.js`는 아라크네 시나리오를 조립하며 약간의 화면·게임 흐름 코드를 보유합니다. 개체 다수 동시 관리가 추가될 때는 Scene/Scenario로 추가 분리 예정.
행동별 모션은 원화 이미지에 적용한 변형/파티클 방식이고, Aseprite 프레임 시트 기반 리깅은 아직 미구현입니다.

## 검증
모듈 smoke 테스트(관리 상태 변화/폭주 전환)와 경로 탐색 검사를 진행.
`npm test`를 실행하면 순수 판정·경로 탐색·모듈 계약에 대한 Node 기본 테스트가 실행됩니다.
